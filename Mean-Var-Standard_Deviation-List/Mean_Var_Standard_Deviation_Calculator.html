Mean-Variance-Standard Deviation Calculator



---

Project Overview


This notebook implements a function that performs statistical calculations on a list of 9 numbers. The function reshapes the input into a 3×3 matrix and computes various statistical measures across rows, columns, and the entire flattened array.



---

Problem Statement


Create a function named calculate() that:



  • Accepts a list of 9 numbers as input

  • Converts it into a 3×3 NumPy array

  • Returns a dictionary containing:

    • Mean (average)

    • Variance (spread of data)

    • Standard Deviation (average distance from mean)

    • Max (maximum value)

    • Min (minimum value)

    • Sum (total)




For each statistic, the function should calculate:



  1. Axis 0 (columns) → list of 3 values

  2. Axis 1 (rows) → list of 3 values

  3. Flattened (entire array) → single float

Function Definition


Complete the calculate() skeleton below. The function should:



  1. Validate that input is a list

  2. Validate that list contains exactly 9 numbers

  3. Reshape the list into a 3×3 matrix

  4. Return a dictionary with the required statistics

In [4]:
def calculate(lst):
    if type(lst)!=list:
        raise TypeError("Please enter a list.")
    elif len(lst)!=9:
        raise ValueError("List must contain nine numbers.")
    numlist = np.reshape(lst,(3,3))
    calculation = {"mean": [list(np.mean(numlist,axis=0)),list(np.mean(numlist,axis=1)),float(np.mean(numlist))],
                   "variance":[list(np.var(numlist,axis=0)),list(np.var(numlist,axis=1)),float(np.var(numlist))],
                   "standard deviation":[list(np.std(numlist,axis=0)),list(np.std(numlist,axis=1)),float(np.std(numlist))],
                   "max":[list(np.max(numlist,axis=0)),list(np.max(numlist,axis=1)),float(np.max(numlist))],
                   "min":[list(np.min(numlist,axis=0)),list(np.min(numlist,axis=1)),float(np.min(numlist))],
                   "sum":[list(np.sum(numlist,axis=0)),list(np.sum(numlist,axis=1)),float(np.sum(numlist))]}

    return calculation
